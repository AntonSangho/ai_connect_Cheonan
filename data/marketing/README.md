# 마케팅 더미데이터 (천안 지역 이벤트·제휴 후보)

마케팅 에이전트 예시의 미션 "천안에서 홍보할 행사·상권·제휴처 후보를 조사하고 우선순위 매기기"에 쓰는 가상 데이터입니다.

> **모든 수치와 일정, 업체명은 가상입니다.** 일부 장소 이름은 실제 천안의 지명을 빌렸지만 행사 일정, 방문자 수, 비용, 업체 정보는 지어낸 값입니다. 실제 판단에 쓰지 마세요.

## 파일

| 파일 | 내용 | 주 용도 |
| --- | --- | --- |
| `events.csv` | 천안 행사 8건(일정, 예상 방문자, 부스 가능 여부, 비용, 접촉 상태) | 홍보 행사 후보 |
| `districts.csv` | 상권 6곳(주 고객, 유동인구, SNS 활동, 임대 수준) | 상권 후보 |
| `partners.csv` | 제휴 후보 8곳(카페, 주점, 학생 단체, 인플루언서 등) | 제휴처 후보 |
| `past_campaigns.csv` | 지난 캠페인 4건(비용, 주문, 매출) | 채널별 효율 비교 |
| `brand_guide.md` | 제품, 톤, 금지 표현, 예산 | 후보를 거르는 기준 |
| `handoff_memo.md` | 전임자 메모(구어체, 일부러 불완전) | 학생이 질문을 만드는 재료 |

## 일부러 넣은 빈틈과 함정

- `events.csv`의 E01은 이미 끝난 행사, E05·E08은 부스 불가라서 걸러야 합니다.
- 부스비를 빈칸으로 둔 행이 있습니다(`booth_fee_krw`).
- 메모의 "학생회 얘기 중"은 `partners.csv` P03과 이어지지만 진행 상태는 확인이 필요합니다.
- 총예산 50만 원 안에서 고르려면 비용과 효율(`past_campaigns.csv`)을 함께 봐야 합니다.

## 나중에 API로 바꿀 때

데이터는 CSV 컬럼 그대로 에이전트에 넘깁니다. 실제 API 연동 시 같은 컬럼 이름을 반환하도록 어댑터만 만들면 에이전트 쪽은 바꾸지 않아도 됩니다.
