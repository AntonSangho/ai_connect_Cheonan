# AI 직무 에이전트 워크숍 — 설계 방향

Oct 8, 2026 · @anton

## 목표

학생은 이틀 동안 아직 전문가가 아닌 직무의 미션을 에이전트와 함께 끝까지 해내고, 처음보다 그 일을 더 잘 설명할 수 있게 됩니다.

| 목표 | 뜻 | 에이전트가 키워 주는 것 |
| --- | --- | --- |
| 이해 | 낯선 직무 자료를 읽고 그 일이 무엇이고 왜 그렇게 하는지 안다 | 인수인계 자료 풀이, 질문에 답하기, 모르는 용어 설명 |
| 생산 | 이해한 것에 나의 관점과 개성을 담아 결과물을 만든다 | 초안·후보·근거 제시. 고르고 다듬는 것은 학생 몫 |

**와우 포인트.** "전공도 경력도 없는데 해냈다." 학생은 가상 전임자의 인수인계 자료와 직무 에이전트만으로 실제 현업 순서대로 미션을 완수합니다.

## 운영 조건

| 조건 | 설계에 반영하는 방식 |
| --- | --- |
| 2일 × 4시간 | 1일차는 Claude와 에이전트 이해, 2일차는 미션 해결 |
| 강사 1인, 멘토 없음 | 현직자 피드백은 직무 에이전트의 "현직자 검토" 단계가 대신합니다. 학생이 단계별 자가 점검표로 스스로 확인합니다 |
| 학생 전원 Claude Pro 1개월 | 에이전트 = Claude 프로젝트(지침 + 인수인계 자료 + 점검표). 워크숍 뒤 남은 기간에도 계속 쓸 수 있습니다 |
| 직무 3개 | 영업(고객 발굴), 마케팅(캠페인 실행), 서비스기획(문제 정의). 기존 에이전트 초안 3개를 그대로 씁니다 |

## 팀 구성과 미션

한 팀이 가상 회사의 제품 하나를 맡고, 팀원 3명이 영업·마케팅·서비스기획을 하나씩 맡습니다. 각자 자기 분야 에이전트와 1:1로 일하고, 마지막에 세 결과를 팀 계획 1장으로 합칩니다. 팀 수는 참여 인원을 보고 정하고, 3으로 나누어 떨어지지 않으면 한 분야를 2명이 맡습니다.

공통 제품 예시: 천안의 수제 김 스낵 브랜드(스마트스토어 판매 중, 해외 진출 검토 중).

| 분야 | 미션 | 전임자 인수인계 자료 | 산출물 |
| --- | --- | --- | --- |
| 영업 | 베트남에서 살 만한 바이어 5곳 찾기 | 인수인계 메모, 기존 거래처 목록, 지난 미팅 기록, 제품 소개서 | 후보 리스트·프로필·우선순위 표 |
| 마케팅 | 2주 안에 첫 주문 50건 만드는 캠페인 | 지난 캠페인 결과, 브랜드 톤·금지 표현, 원가·예산표 | 소개글·카피·혜택안·지표 1장 |
| 서비스기획 | 주문·배송 불편 Top 3 찾기 | 1\~2점 리뷰 30건 이상, 고객센터 문의 유형, 이전 기획서 1건 | 리뷰 분류표·문제 정의서 1장 |

에이전트는 조사·정리·초안을 맡고, 고르는 칸(우선순위 확정, 타깃·메시지 선택, 문제 1개 선택)은 비워 둡니다. 그 칸을 채우는 일이 학생의 생산이고, 개성이 들어가는 자리입니다.

## 2일 진행표

1일차에는 에이전트가 무엇인지 이해하고 인수인계를 받습니다. 2일차에는 미션을 끝까지 해결합니다. 시간은 각 날 시작 기준입니다.

**인수인계 자료 예시 (영업, 김 스낵 브랜드).** 전임자가 남긴 것처럼 보이는 불완전한 자료 4개를 줍니다. 정리되어 있지 않고 빈틈이 있어서, 학생이 질문을 만들게 됩니다.

- **인수인계 메모 1쪽**: "베트남은 작년에 샘플만 보냈고 반응은 좋았음. 다만 대형 마트는 포장 문의가 많았음. 담당자 이직으로 연락이 끊긴 곳 있음." (누가 끊겼는지는 적혀 있지 않음)
- **기존 거래처 목록**: 국내 거래처 12곳과 샘플 발송 3곳의 이름·국가·마지막 연락일
- **지난 미팅 기록**: 하노이 유통사와의 30분 통화 메모. "가격보다 유통기한을 먼저 물어봄"
- **제품 소개서**: 맛 3종, 용량, 소비기한, 인증 현황. 해외 인증은 "준비 중"으로만 적혀 있음

학생이 던질 질문의 예: "연락이 끊긴 곳은 어디인가요?", "소비기한이 몇 개월인가요?", "해외 인증은 언제 끝나나요?" 마케팅(지난 캠페인 결과 표, 금지 표현 목록)과 서비스기획(1\~2점 리뷰 30건, 고객센터 문의 유형)도 같은 방식으로 만듭니다.

| 날 | 시간 | 활동 | 남는 것 |
| --- | --- | --- | --- |
| 1일차 | 0:00–0:20 | 오리엔테이션, 팀·분야 배정, **사전 설명**(AI 없이 5분) | 사전 설명 기록 |
| 1일차 | 0:20–1:20 | Claude 기초: 질문하기, 파일 첨부, 웹 검색, 답 검증하기 | 연습 대화 |
| 1일차 | 1:30–2:20 | 에이전트 이해: 챗봇과 무엇이 다른가(지침·자료·규칙). 내 직무 에이전트를 프로젝트로 직접 세팅 | 내 에이전트 |
| 1일차 | 2:20–3:30 | 인수인계 받기: 에이전트와 자료를 읽고 모르는 것을 묻는다. "전임자에게 물을 질문 5개" 만들기 | 질문 5개, 미션 한 줄 |
| 1일차 | 3:30–4:00 | **중간 설명**: 팀원에게 1분씩 "내일 내가 할 일" 설명 | 내일 계획 |
| 2일차 | 0:00–0:15 | 미션 재확인, 자가 점검표 안내 | — |
| 2일차 | 0:15–2:15 | 분야별 미션: 에이전트가 조사·초안을 내고, 학생이 고르는 칸을 직접 채운다(휴식 10분 포함) | 분야 산출물 |
| 2일차 | 2:15–2:45 | AI 현직자 검토 → 수정 1회 | 검토 의견, 수정본 |
| 2일차 | 2:45–3:15 | 팀 통합: **서로 가르치기**(각자 자기 분야를 팀원에게 3분 설명) → 팀 계획 1장 | 팀 계획 1장 |
| 2일차 | 3:15–3:45 | **사후 설명** + 성장 리포트 | 성장 리포트 |
| 2일차 | 3:45–4:00 | 팀별 공유, 간단 설문 | 설문 |

## 성장 체크 — 설명으로 이해도 재기

같은 질문에 대한 자기 설명을 시작과 끝에 받아 비교합니다. 근거는 세 가지입니다. 자기설명(self-explanation)은 이해를 깊게 하고 그 수준을 드러냅니다. 가르치며 배우기(파인만 기법)는 어디서 막히는지 보여 줍니다. SOLO 분류는 설명의 수준을 단계로 나눕니다. 매뉴얼 10단계의 사전·사후 비교를 시험 대신 설명으로 하는 방식입니다.

**설명 질문 3개** (사전·사후 동일, AI와 자료 없이 직접 작성)

1. **무엇**: 이 직무는 무슨 일을 하고, 무엇으로 성과를 평가받나요?
2. **어떻게·왜**: 내 미션은 어떤 순서로 풀어야 하고, 각 단계는 왜 필요한가요?
3. **나의 판단**: AI에게 맡길 일과 내가 정해야 할 일은 무엇인가요? 나는 무엇을 골랐고 왜 골랐나요?

**측정 순서**

1. **사전 설명** (1일차 시작, 5분): 모르는 것도 있는 그대로 적습니다. 평가는 하지 않고 기록만 합니다.
2. **중간 설명** (1일차 끝, 1분): 팀원에게 말로 설명하고, 막힌 곳을 메모합니다.
3. **서로 가르치기** (2일차 팀 통합, 3분): 다른 분야 팀원이 내 설명만 듣고 이해했는지 되묻습니다.
4. **사후 설명** (2일차, 10분): 같은 질문 3개에 답하고, 성장 체크 에이전트가 꼬리 질문 1개를 더 던집니다(예: "제품이 바뀌면 무엇을 다르게 하겠어요?").
5. **자기 예측 → 리포트**: 리포트를 보기 전에 학생이 "나는 몇 단계에서 몇 단계로 갔다"를 먼저 적습니다. 그다음 에이전트의 판정과 비교해 성장을 스스로 알아차렸는지 확인합니다.

**설명 수준 루브릭** (SOLO를 4단계로 줄임, 예시는 영업)

| 수준 | 설명의 모습 | 예시 |
| --- | --- | --- |
| 1 단편 | 용어 하나, 막연한 정의 | "영업은 물건 파는 일" |
| 2 나열 | 단계나 요소를 여럿 말하지만 서로 잇지 못함 | "시장 조사, 바이어 찾기, 제안을 한다" |
| 3 연결 | 단계 사이의 순서와 이유를 설명 | "매출순으로 후보를 추려야 제안할 곳을 좁힐 수 있다" |
| 4 확장 | 다른 상황에 적용하거나 한계를 말함 | "국내 편의점이면 국가 대신 채널을 보고, 기존 거래처는 뺀다" |

**성장 리포트에 들어가는 것**: 질문별 사전→사후 수준, 그 판정의 근거가 된 학생 문장 인용, 새로 쓰게 된 용어, 남은 오개념 1개, 다음에 해 볼 것 1개. 에이전트는 점수보다 변화를 말하고, 근거 없는 칭찬은 하지 않습니다.

## 준비와 파일럿

**준비물**

- [ ] 직무 에이전트 3개: 프로젝트 지침(역할, 6단계 워크플로우, 규칙 5개, 현직자 검토 단계) + 지식 파일
- [ ] 성장 체크 에이전트 1개: 질문 3개, 루브릭, 꼬리 질문, 리포트 양식
- [ ] 분야별 전임자 인수인계 자료 팩 3종(새로 제작)
- [ ] 분야별 자가 점검표(초안의 통과 기준 5개 기반)
- [ ] 배포 방식 확인: Pro 개인 계정끼리 프로젝트를 공유할 수 있는지. 안 되면 지침과 파일 묶음을 나눠 주고 1일차에 학생이 직접 세팅합니다

**안전망**

| 위험 | 대비 |
| --- | --- |
| KOTRA·대학알리미·배달앱 등 자동 접근 차단(초안 테스트에서 확인) | 필요한 원문을 인수인계 자료 팩에 미리 넣어 둡니다 |
| 실행이 길고 무거움(영업 테스트 1회 약 19분, 검색 216회) | Pro 사용 한도를 파일럿에서 확인하고, 미리 돌려 둔 결과를 예비로 둡니다 |
| 강사 1인에게 질문이 몰림 | 자가 점검표와 AI 현직자 검토로 먼저 해결하고, 강사는 막힌 팀만 도웁니다 |

**파일럿(2\~3명) 확인 항목**

- 활동별 실제 소요 시간이 진행표와 맞는지
- 미션 중 Pro 사용 한도에 닿는지, 어디서 막히는지
- 성장 체크 에이전트의 판정이 강사가 같은 루브릭으로 매긴 수준과 맞는지
- 학생의 자기 예측과 리포트가 얼마나 어긋나는지, "성장했다"는 체감이 있는지
