# AI Connect Cheonan — AI 직무 에이전트 워크숍

대학생이 희망 직무의 AI 에이전트와 함께 실제 직무 미션을 해결해 보는 2일(하루 4시간) 워크숍의 설계 자료입니다.

- **대상**: 대학생 (영업 · 마케팅 · 서비스기획 직무 지망)
- **목표**: 낯선 직무를 **이해**하는 능력과, 나의 개성을 담아 결과물을 **생산**하는 능력을 에이전트로 키우는 경험
- **방식**: 팀이 가상 회사의 제품 하나를 맡고, 팀원이 분야를 하나씩 나눠 전임자 인수인계 자료와 직무 에이전트로 미션을 끝까지 해결
- **성장 체크**: 사전·사후 자기 설명을 SOLO 기반 4단계 루브릭으로 비교

- 설계는 공도 교수학습 설계 매뉴얼(딕과 캐리 모형, ARCS)과 직무별 에이전트 초안(영업 · 마케팅 · 서비스기획)을 바탕으로 했습니다.
